# html-generator 用户手册

**版本：v1.13.1**

面向使用者的操作指南。想了解内部架构与二次开发，请看《技术手册》。

---

## 1. 这个技能解决什么问题

你有一份内容（数据、结论、方案、教程），想让它变成**一份好看的文档**，而不是一堆散乱的文字。

html-generator 做的是：

1. 根据你的需求**生成一份 HTML 文档**（视觉精良、离线自包含、双击就能打开）
2. 需要时**一键转成 Word / PDF / Markdown**

关键取舍：**HTML 是源文件，其余三种是派生格式。** 所有修改都在 HTML 上做，需要交付哪种格式再转哪种。

---

## 2. 三步上手

### 步骤 1：说出你的需求

```
写一份 Q3 渠道运营报告
```

不需要指定格式、配色、版式。技能会自动判断：

- 用哪种**文档模式**（7 种）
- 用哪组**调色板**（8 组）
- 要不要**配图**（默认不要）

### 步骤 2：确认产出

生成的 HTML 会保存在你的工作目录，文件名是中文主题名，如 `Q3渠道运营报告.html`。

如果文档含图表，技能会自动跑数学校验并截图核对，通过后才交付。

### 步骤 3：按需转换

```
把这份报告转成 Word
```

转换前会列出降级项（如"卡片会变成表格""SVG 图表会变成 PNG"），你确认后才执行。

## 3. 怎么控制产出效果

### 3.1 选文档模式

直接说场景关键词，技能自动匹配：

| 你说的话里有 | 技能会选 | 效果 |
|---|---|---|
| 方案 / 调研 / 报告 | `mode-doc` | 传统文档流，标题→正文→小节 |
| 对比 / 选型 / A vs B | `mode-compare` | 多列并排卡片，推荐项高亮 |
| 周报 / 进度 / 事故 | `mode-status` | 状态胶囊 + 时间线 + 大数字 |
| 教程 / 指南 / 入门 | `mode-explainer` | 正文 + 可折叠深挖 + 代码块 |
| 数据 / 指标 / 简报 | `mode-dashboard` | 大数字 + 迷你图 + 表格 |
| 长页 / 品牌 / 专题 / 年度回顾 | `mode-deck` | 整屏滚动吸附 + Hero 渐变 |

想强制指定，直接点名：

```
改用 dashboard 模式呈现这些数据
```

### 3.2 调配色板

| 调色板 | 什么时候用 |
|---|---|
| 墨蓝 | 技术、数据、项目、系统、架构（默认，最百搭） |
| 暖金 | 活动、旅行、生活、人文 |
| 青绿 | 教育、健康、环保 |
| 玫红 | 营销、创意、社交 |
| 深蓝金 | 简历、年报、商务、提案 |
| 紫韵 | 设计、艺术、时尚、文化 |
| 橙韵 | 运动、餐饮、社群 |
| 灰调 | 简历、学术、技术文档、极简 |

```
用紫韵色重新生成这份方案
```

### 3.3 控制配图

**默认不加图。** 想要图，明确说：

- `给每个章节配一张 AI 生成的插图` —— 调用图像生成
- `用我这张图做封面：D:\img\cover.png` —— 用本地图
- `配这个 URL 的图：https://...` —— 下载后内嵌

图片一律 base64 内嵌到 HTML 里，所以文件可以离线打开、发给别人也不会丢图。

### 3.4 加交互

默认不写 JavaScript（保证离线自包含 + 转换保真）。需要交互时点名：

```
加上 Tab 切换 / 可折叠区块 / 表格搜索 / 返回顶部
```

注意：交互在转成 Word / PDF / Markdown 后会丢失（Tab 全部展开、折叠全部展开），转换前会提醒你。

## 4. 图表：37 种怎么选

这是本技能的强项。所有图表坐标都由程序计算，生成后强制数学校验 + 截图核对。

### 4.1 选型速查

| 你想表达什么 | 用什么 |
|---|---|
| 各部分占整体的比例（≤6 类） | 饼图 / 环形图 |
| 占比，但要突出差异（6–12 类） | 玫瑰图 |
| 占比，类别很多（>12） | 树图 / 堆叠柱状图 |
| 趋势随时间变化 | 折线图 / 面积图 |
| 趋势 + 构成 | 堆叠面积图 / 河流图 |
| 预测区间 / 置信带 | 区间图 |
| 阶跃变化（利率、库存档位） | 阶梯折线图 |
| 两个时间点对比 | 斜率图 |
| 排名 | 横向条形图排行榜 |
| 两组对比（男女、去年今年） | 金字塔图 |
| 正负影响（敏感性分析） | 双向条形图 / 龙卷风图 |
| 数值分布 | 直方图 / 箱线图 / 小提琴图 |
| 两个变量的关系 | 散点图 / 气泡图（气泡多一维） |
| 带误差的均值对比（A/B 测试） | 误差棒图 |
| 完成度 / KPI | 仪表盘 / 子弹图 |
| 财务增减拆解 | 瀑布图 |
| 转化流程流失 | 漏斗图 |
| 流量 / 资金流向 | 桑基图 |
| 日期上的强度分布 | 日历热力图 |
| 二维矩阵上的强度 | 热力图 |
| 抓主要矛盾（二八） | 帕累托图 |
| 两个指标 + 一个趋势（双轴） | 组合图 |
| 战略定位（2×2） | 象限图 |
| 文本频次 | 词云 |
| 表格内嵌趋势 | 迷你图 |
| 项目排期 | 甘特图 |

### 4.2 直接点名即可

```
用饼图看 GMV 占比，用折线图看 6 个月趋势
```

```
分析用户转化：漏斗图看各级流失，热力图看各渠道 × 各月份的转化率
```

### 4.3 图表质量是怎么保证的

1. **坐标必须程序计算**：禁止手写 SVG 的 `path` 坐标，一律用 Python 算
2. **生成后数学校验**：跑 `chart_validator.py`，检查数据点数 = 标签数、角度和 = 360°、坐标不越界、面积比 = 数值比等
3. **截图 + 视觉核对**：数学校验过了还要肉眼看一遍形状对不对

第三歩不是走过场——实测中抓到过"瀑布图减量柱被画成增量色""小提琴图画成锯齿菱形"这类脚本查不出、肉眼一看就不对的问题。

## 5. 格式转换

### 5.1 三种格式的保真度

| 格式 | 语义 | 视觉 | 适合什么场景 |
|---|---|---|---|
| **Word** | 95% | 70% | 需要继续编辑、走审批流 |
| **PDF** | 95% | 95% | 定稿分发、打印 |
| **Markdown** | 90% | — | 放进知识库、Git 仓库、喂给其他工具 |

HTML 本身适合：直接分享、嵌进网页、做交互。

### 5.2 转换前会告诉你代价什么

技能会先跑影响分析，列出降级项再问你确认。常见的：

| HTML 里的效果 | 转成 Word | 转成 PDF | 转成 Markdown |
|---|---|---|---|
| 卡片布局 | 变成表格 | 保留 | 变成列表 |
| 时间线 | 变成两列表格 | 保留 | 变成有序列表 |
| 渐变 / 圆角 / 阴影 | 丢失 | 保留 | 丢失 |
| SVG 图表 | 截图成 PNG | 保留 | **只剩文本标签，数据丢失** |
| 交互动画 | 丢失 | 丢失 | 丢失 |
| 表格型图表（热力图/甘特图） | 原生表格 | 保留 | Markdown 表格 |

### 5.3 重要提醒

> ⚠️ **转 Markdown 会丢掉所有 SVG 图表的数据。**
> 如果你需要保留图表，请选择 HTML / Word / PDF。
> 这一点在转换前的降级清单里会明确提醒。

## 6. 常见问题

**Q：生成的 HTML 打不开 / 样式乱了？**
A：HTML 是离线自包含的（不引用外部 CSS/JS/字体/图片），任何现代浏览器都能直接打开。如果样式异常，检查是否用了过旧的浏览器。

**Q：为什么我的文档没有图？**
A：默认不加图。想要请明确说"配图"。

**Q：转换失败怎么办？**
A：转换依赖 Python 虚拟环境，首次运行会自动创建。若报错，看错误信息里是否提示缺少依赖（如 Pillow、pymupdf）——这两个是可选的，缺失只影响图片压缩和 PDF 尾页检测，不影响主流程。

**Q：能改已经生成的文档吗？**
A：能。直接说"把第三章的数据更新一下"或"加入更多图示"，技能会进入增量编辑模式，只改需要改的部分，不重新生成整份。

**Q：转换一定要用内置脚本吗？**
A：是。技能明确禁止手写转换脚本——内置脚本针对 25 种 IR 语义结构（折叠卡片、指标卡、时间线等）有专门处理逻辑，手写脚本会大量丢数据。
