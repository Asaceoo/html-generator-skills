### 2.2 语义 IR 体系（12 块级 + 2 辅助 → 25 种 IR 映射）

生成端唯一硬性要求：关键结构最外层加语义 class（`title/heading/paragraph/card/table/timeline/stat/code/callout/image/list/end_page` + 辅助 `cite/source-list`），转换器据此归约 IR 并按内置矩阵映射到 Word/PDF/Markdown（如 `timeline`→Word两列表格→PDF保留→MD有序列表；`card`→无边框表格+shading）。**映射逻辑全部内置在脚本中，禁止调用方手写转换**（历史上手写脚本曾导致折叠卡片内12条数据全部丢失）。

可选 `data-*` 属性：`data-level/variant/cols/lang/caption/float`。Flexbox/Grid 必须带 `data-layout/data-cols` 标注，转换脚本读 data 属性而非 CSS。

### 2.3 关键机制

- **占位符替换**：骨架中 `{primary}` 等占位符必须替换为 palettes.json 真实色值，否则 CSS 全部失效
- **图表质量三保障**：① 坐标程序计算（`x = cx + r*sin(rad), y = cy - r*cos(rad)`，large-arc-flag 按 sweep>180°）② chart_validator.py 数学校验（饼图角度总和360°、path-legend颜色一致、柱状图条形=标签=数据项、折线点=标签数）③ 截图+视觉模型复核
- **chart_unknown 三层降级**：Playwright截图插入PNG → 递归提取SVG文本重建表格 → 零文本装饰元素跳过
- **交互组件（L1级）**：仅用户触发，从 interactive-pack.md 选取，转 Word/PDF/MD 时交互丢失内容保留（Tab/折叠全部展开）
- **甘特图约束**：时间维度按季度合并≤8列，禁 overflow-x 滚动
- **表格列宽**：按各列最长内容字符数比例分配

### 2.4 large-html-iterative-editing.md（v1.0 新增的编辑增强）

本仓库 v1.0 收录技能自进化更新沉淀的大型 HTML 迭代编辑方法论（源自一次"95个知识点批量插入五维解读、50幅SVG图示、6轮增强"的实战）：

1. **edit/multiedit 跨行锚点失效**：报 `Could not find oldString` 但 `Contains` 为真（LF 行尾 vs 工具 CRLF 匹配）→ PowerShell `[IO.File]::ReadAllText + String.Replace` 可靠替代（实测 69+ 处插入零失败）
2. **锚点唯一性三规则**：禁前缀书名锚点；警惕条目级与章节级同名资源块双匹配；防"插入后锚点复活"（新块闭合标签+原资源行）导致二次插入
3. **multiedit 非原子性**：报错≠零改动——报错后必查文件实际状态，禁止盲目重发
4. **PowerShell 中文引号截断**：内容用弯引号 `""`，HTML 属性用转义 `` `" ``
5. **每轮验证套件**：div平衡/块计数/逐条目覆盖/图示编号/闭合标签
6. **重复块清理**：定位→从后往前按行删除→写回保持 LF

## 3. knowledge-handbook-builder 技术架构

### 3.1 五阶段工作流

```
Phase 1 深度调研（每轮≤2次搜索，关键数据双源交叉验证）
Phase 2 知识体系设计（category → knowledge-block → kp 三级层级，图号全局无缺口）
Phase 3 骨架生成（assets/handbook-template.html 起步）
Phase 4 SVG图示设计（13类图型模式库 + 等轴测坐标公式）
Phase 5 填充/批量编辑/验证（handbook_tools.py 原子操作）
```

### 3.2 handbook_tools.py 命令规范（零依赖 Python 3.8+）

| 命令 | 功能 | 退出码 |
|------|------|--------|
| `validate <file>` | 6项全套验证（div平衡/资源覆盖/deep统计/重复检测/图号/闭合） | 0=PASS / 1=FAIL |
| `stats <file>` | 规模统计 | 0 |
| `anchors <file>` | kp锚点列表 `行号\|格式\|term\|书名` | 0 |
| `dupres <file>` | 重复书名+前缀冲突预警 | 0 |
| `dedup <file> [--apply]` | 重复deep检测；--apply删除（每kp区域保留第一个） | 0=无重复 / 1=发现(dry-run) |
| `replace --old O --new N --expect 1` | 锚点验证原子替换 | 0=成功 / 2=未找到 / 3=次数不符 |

**核心设计**：
- **原子性**：锚点未找到/次数≠预期 → 拒绝且文件不变（根治误插与二次插入）
- **行尾自适应**：LF 锚点自动适配 CRLF 文件（双向兼容），写回保持原行尾风格（newline='' + split("\n") 保真往返）
- **文件通道**：`--old-file/--new-file` 规避 shell 中文引号转义
- **无BOM UTF-8**：读写统一 `utf-8`，写回不加 BOM

### 3.3 MCP 服务器（mcp_server.py）

FastMCP stdio 封装，暴露 6 个工具：`validate_handbook / handbook_stats / extract_anchors / duplicate_res_check / dedup_deep_blocks / safe_replace`，通过 `redirect_stdout` 捕获 CLI 函数输出并附退出码。

### 3.4 知识点七层结构（HTML 契约）

```
.kp（容器）
├── .kp-term         术语标题
├── .kp-explain      通俗解释（含<strong>与生活化类比）
├── .deep（五维解读容器）
│   ├── .dim.assumption  暗含假设（红 #dc2626）
│   ├── .dim.principle   第一性原理（蓝 #2563eb）
│   ├── .dim.pro         专业解读（绿 #16a34a）
│   ├── .dim.vivid       形象化（橙 #f59e0b）
│   └── .dim.ext         扩展（紫 #7c3aed）
└── .res             资源块（书籍 + B站搜索关键词）
```

验证契约：deep块数 = kp数；dim行数 = 5×kp数；任一kp区域内 deep ≤ 1。

### 3.5 SVG 图示模式库（13 类）

三维爆炸 / 3D等轴测（坐标公式：`sx = cx+0.866x−0.866y; sy = cy+0.5x+0.5y−z`）/ 剖面（45°pattern）/ 决策树 / 甘特图 / 流程图 / 雷达图（r=110正五边形顶点）/ 对比图 / 曲线图（对数X轴）/ 柱状图 / 阶梯图 / 冰山图 / 时间线路径。防重叠三原则：panel独立 translate、文字与图形间距≥10px、说明统一底部条带。

## 5. 编辑安全工程（两技能共享的防错知识）

| 事故模式 | 根因 | 解法 |
|----------|------|------|
| 跨行锚点替换报错但内容存在 | edit工具CRLF匹配 vs 文件LF | handbook_tools.py replace（行尾自适应） |
| deep块误插到错误位置 | 书名前缀匹配（Replace替换所有） | 锚点带完整后缀+`--expect 1`自动拒绝 |
| deep块重复2次 | 插入后锚点复活+命令重发 | 同锚点只执行一次+`dedup --apply` |
| multiedit部分应用后报错 | 非原子实现 | 分批(3-7/批)+报错后必查文件状态 |
| 中文内容PS截断 | ASCII双引号终止字符串 | 弯引号/文件通道 `--new-file` |
