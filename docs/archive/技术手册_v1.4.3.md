## 4. cmd_sources 实现详解（v1.4.3）

```python
[1] 证据级别分布: 统计 .ev-a/.ev-b/.ev-c/.ev-pending 出现次数 → 占比
[2] 来源清单: pro 维标准号正则提取 + kp_res 书名 → 去重
[3] 存疑项: kp 区域含 ev-c/ev-pending/🔎待核实/待联网核实 → 列出 (行号, term)
[4] 未覆盖项: 固定提示由 Phase 1 盲区清单人工填写
[5] kp 元数据: data-updated 属性在 kp 块前 4 行内计数 → 覆盖率
```

**实现要点**：
- pending 计数只认显式标记（`ev-pending` / `🔎待核实`），不数正文"待核实"字样（避免 term 含该词误报）
- 来源清单 = 标准号（GB/ISO/EN…）+ 书籍（kp_res 提取）双通道去重
- 输出即附录前三要素的 Markdown 源文本，Phase 5 插入模板 `appendix-research` category
