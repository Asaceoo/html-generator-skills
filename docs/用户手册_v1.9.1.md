## 1. 它解决什么问题

一句话：**一次内容编排，四种格式输出（HTML / Word / PDF / Markdown）。**

你只需要说清要什么内容，技能生成一份视觉精良、离线自包含的 HTML；需要时再一键转成 Word、PDF、Markdown 交付。

| 你的场景 | 得到什么 |
|---|---|
| 写调研报告 / 技术方案 / 项目周报 | 一份排版完整的 HTML，可转 Word 给领导、转 PDF 存档 |
| 做方案对比 / 产品选型 | 多列并排卡片 + 推荐项高亮的对比页 |
| 沉淀教程 / 使用指南 | 正文 + 代码块 + 可折叠深挖的教学页 |
| 做数据简报 / 经营概览 | 大数字指标 + 迷你图 + 数据表格的看板页 |
| 做品牌长页 / 活动专题 / 年度回顾 | 整屏滚动吸附的叙事长页 |
| 已有文档要继续加内容 | 增量编辑模式，锚点定位后插入新块，不重做整份文件 |

**核心理念：生成放开、转换归约。** 生成端不设固定块模板（视觉自由设计）；转换端靠轻量语义 class 把自由 HTML 归约到 25 种 IR 语义，再映射到 Word / PDF / Markdown。

> HTML 是源文件，Word / PDF / Markdown 是派生格式——以 HTML 为准，转换是尽力而为的语义归约。

## 2. 快速开始

### 2.1 安装

```bash
# 方式 A：克隆整个仓库（含两个技能 + 手册）
git clone https://github.com/Asaceoo/html-generator-skills.git

# 方式 B：只装 html-generator —— 下载 Release 里的 html-generator-vX.Y.Z.zip，
# 解压为 html-generator/ 后放入你的技能目录（如 ~/.workbuddy/skills/）
```

### 2.2 生成一份文档

对话里直接说：

> 帮我生成一份《2026 年智能家居行业调研报告》

AI 会自动完成：选文档模式（7 选 1）→ 选调色板（8 选 1）→ 判断是否需要配图 → 生成 `2026年智能家居行业调研报告.html` 到你的工作目录并预览。

想覆盖自动判断，直接说：

> 用对比模式，配色用深蓝金，转 Word

### 2.3 转换格式（三种入口）

```bash
# Windows（推荐入口脚本，自动管理 Python 环境）
powershell -File html-generator/scripts/win/convert.ps1 -Format docx -InputFile 报告.html -OutputFile 报告.docx -Yes

# macOS / Linux
bash html-generator/scripts/unix/convert.sh --format pdf --input 报告.html --output 报告.pdf --yes

# 也可以直接调 Python（环境已就绪时最快）
python html-generator/scripts/html2docx.py 报告.html 报告.docx
python html-generator/scripts/html2pdf.py  报告.html 报告.pdf
python html-generator/scripts/html2md.py   报告.html 报告.md
```

`-Yes` / `--yes` 表示"已知晓降级，跳过确认"。不带它时，Word / PDF 转换会在检测到降级项后停下等你确认。

### 2.4 转换前先看会掉什么

```bash
python html-generator/scripts/impact_analyzer.py 报告.html --format docx --json
```

返回示例（真实输出）：

```json
{"need_remind": true, "items": [
  "有 3 个 callout 将降级为带底色段落",
  "有 1 个 timeline 将降级为两列表格（时间样式丢失）",
  "有 stat 指标卡将降级为普通表格",
  "有 card 卡片将降级为普通表格",
  "未知图表将降级为截图或数据重建表格/列表（图形视觉丢失，数据保留）",
  "Flexbox/Grid 布局将重建为表格",
  "SVG 将降级为 PNG"
], "format": "docx"}
```

`need_remind=false` 表示全是基础语义、无结构降级，可直接转。

## 3. 7 种文档模式

| 模式 | 适用场景 | 结构特征 |
|---|---|---|
| mode-doc | 技术方案、调研报告、通用文档 | 标题 → 正文 → 小节，传统文档流 |
| mode-compare | 方案对比、产品选型 | 多列并排卡片，推荐项高亮 |
| mode-status | 项目周报、进度汇报、事故报告 | 状态胶囊 + 时间线 + 指标数字 |
| mode-explainer | 教程、使用指南、概念讲解 | 正文 + 可折叠深挖 + 代码块 |
| mode-dashboard | 数据概览、经营简报 | 大数字指标 + 迷你图 + 表格 |
| mode-deck | 品牌故事、活动专题、年度回顾 | 整屏滚动吸附 + Hero 全屏渐变 |
| mode-auto | 没有明显匹配时 | 精简骨架，自由发挥 |

## 5. 转换保真度与降级

| 格式 | 语义保真 | 视觉保真 | 说明 |
|---|---|---|---|
| HTML → Word | 95% | 70% | 内容完整；卡片 / 时间线 / 画廊降级为表格或段落 |
| HTML → PDF | 95% | 95% | 近乎 1:1；仅动画、交互不可静态呈现 |
| HTML → Markdown | 90% | — | 保留标题 / 列表 / 表格 / 代码块结构，视觉不保留 |

**常见降级（Word 侧）**

| HTML 效果 | Word 中 |
|---|---|
| 纯色背景 | 保留为单元格 shading |
| 渐变 / 圆角 / 阴影 | 丢失（Word 文档模型不支持） |
| Flexbox / Grid | 按 `data-cols` 重建为表格 |
| 时间线 | 两列表格（时间列加粗） |
| SVG 图表 | 截图转 PNG 插入（或提取数据重建表格） |
| 交互组件（Tab / 折叠 / 搜索） | 交互丢失，内容全部展开保留 |
| cite 上标引用 | 保留 `[N]` 文本，跳转链接丢失 |

转换完成后，AI 会主动把降级项以表格告知你，不会静默完成。

## 6. 图表怎么保证不出错

生成含 SVG 图表的文档时，有两道校验：

```bash
# 1) 数学校验：角度和 / 坐标连续性 / 图例与扇区配色一致 / 柱数=标签数=数据项数
python html-generator/scripts/chart_validator.py 报告.html

# 2) 转换后对账（Word）：自动打印
# [INFO] 图表产出核对通过：1 个 SVG/Canvas 图表容器已全部产出（截图 1 / 重建 0）
```

饼图 / 环形图的 `path` 坐标必须由程序计算（`x = cx + r·sin θ`、`y = cy - r·cos θ`），禁止手写；配色用数组统一管理，扇区 `fill` 与图例 `swatch` 引用同一份数据。

## 7. 常见问题

**Q：需要联网吗？**
A：生成 HTML 完全离线（不引外链 CSS / JS / 图片 / 字体）。转换脚本首次运行需装依赖（含 Playwright Chromium，约 100MB），之后离线可用。

**Q：图片能进 Word / PDF 吗？**
A：能。图片在生成阶段即 base64 内嵌，转换时直接提取。SVG 在 Word 中降级为 PNG，PDF 保留矢量。

**Q：为什么 Word 里渐变和圆角没了？**
A：Word 文档模型不支持。转换前的 `impact_analyzer` 会逐项列明，转换后 AI 也会主动告知。

**Q：转换时提示 conda 创建失败？**
A：正常兜底。脚本会自动回退到 venv，并写入失败标记，之后不再重复尝试（避免每次空等）。

**Q：Word 转换日志里中文是乱码？**
A：v1.9.1 起已修复——脚本改为沿用宿主控制台编码输出，不再无条件输出 UTF-8。仍遇到乱码时，把宿主代码页切到 65001（`chcp 65001`）再运行。

**Q：能加交互吗？**
A：能。明确要求"可交互 / 可筛选 / Tab 切换 / 可折叠"时才会启用，组件来自 `references/interactive-pack.md`，CSS 与 JS 直接内联，总量控制在 ~2KB。交互在 Word / PDF / Markdown 中丢失但内容完整保留。

**Q：一次能生成多长？**
A：单文件即可，无硬性上限。已有大型 HTML 要继续加内容时走增量编辑模式（锚点定位 → 块插入 → 结构验证）。

## 8. 版本与发布

版本号唯一来源是仓库根 `VERSION`，两份手册的文件名与正文版本号随它同步。维护者发版：

```bash
python scripts/release.py --part minor   # 递增版本号 → 归档旧手册 → 生成新版手册 → 打包 zip
```

产物：`dist/html-generator-vX.Y.Z.zip`，可直接作为 Release 附件，解压即得完整技能目录。
